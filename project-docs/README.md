# ملفات مرجعية — مشروع مصحف التدبر

هذا المجلد يحتوي الملفات المرجعية الأساسية اللي لازم تُراجَع قبل بناء أي سورة جديدة أو تعديل محتوى قائم في مشروع "مصحف التدبر".

> **المعيار المعتمد: سورة البقرة.** أي سورة جديدة تُبنى على هيكلها: معاني المفردات كـ tooltips داخل النص، تقسيم الأقسام الفرعية بطول النص لا بعدد الآيات، والفهرس عبر `tadabbur-toc.js` + `subsections` في `info.json`.

## الملفات

- **template.html** — التيمبلت الكامل لبناء سورة جديدة من الصفر: كتلة الـCSS الإلزامية (متضمنة كلاس `.wq`)، محرر الملاحظات الكامل، شريط التنقل، `verse-modal-overlay`، **الأصول الخمسة الإلزامية في الـhead**، قسم معاني المفردات، قسم معيار التقسيم، آلية العمل خطوة بخطوة، وقائمة الفحص الذاتي. **مرجع إلزامي** قبل أي عمل على سورة أو محور جديد.

- **paragraph-order.md** — ترتيب عناصر القسم الفرعي + معيار طول القسم بالأرقام.

- **notes.md** — ملاحظات أسلوب كتابة المحتوى (المعنى التفصيلي، معاني المفردات، قاعدة القوس).

## الأصول الخمسة الإلزامية في `<head>` (بالترتيب)

```html
<link rel="stylesheet" href="../../../assets/tadabbur.css">
<script src="../../../assets/quran-data.js"></script>
<script type="module" src="../../../assets/firebase-sync.js"></script>
<script src="../../../assets/tadabbur-engine.js"></script>
<script src="../../../assets/tadabbur-toc.js"></script>
```

غياب `tadabbur-toc.js` يُسقط الفهرس بالكامل رغم أن الصفحة تبدو سليمة.

## ملاحظة
هذه الملفات مرجعية فقط ولا تُعرض للمستخدم النهائي في الموقع — الغرض منها توحيد آلية العمل عند البناء أو التعديل مستقبلاً (بما في ذلك جلسات جديدة بدون حاجة لإعادة رفع الملفات من المستخدم).
