# ملفات مرجعية — مشروع مصحف التدبر

هذا المجلد يحتوي الملفات المرجعية الأساسية اللي لازم تُراجَع قبل بناء أي سورة جديدة أو تعديل محتوى قائم في مشروع "مصحف التدبر".

## الملفات

- **template.html** — التيمبلت الكامل لبناء سورة جديدة من الصفر: يحتوي كتلة الـCSS الإلزامية، محرر الملاحظات الكامل، شريط التنقل، verse-modal-overlay، آلية العمل خطوة بخطوة، وقائمة الفحص الذاتي قبل التسليم. **مرجع إلزامي** قبل أي عمل على سورة جديدة أو محور جديد.

- **notes.md** — ملاحظات حرجة عن أسلوب كتابة المحتوى:
  - المعنى التفصيلي يُكتب أسفل كل آية مباشرة (منفصلة، آية واحدة لكل ayah-note-block، مش تجميع عدة آيات).
  - معاني المفردات: تُكتب معاني الكلمات الغريبة فقط (مش آيات مجمعة)، وكل الكلمات الغريبة في القسم يجب تغطيتها.

- **paragraph-order.md** — الترتيب الرسمي لعناصر أي قسم فرعي (sub-block):
  نص الآيات ← معاني المفردات ← المعنى الإجمالي ← التدبر ← المعنى التفصيلي

## ملاحظة
هذه الملفات مرجعية فقط ولا تُعرض للمستخدم النهائي في الموقع — الغرض منها توحيد آلية العمل عند البناء أو التعديل مستقبلاً (بما في ذلك جلسات جديدة بدون حاجة لإعادة رفع الملفات من المستخدم).
