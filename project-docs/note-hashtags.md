# هاشتاجات الملاحظات

- عند إضافة الملاحظة أو تعديلها، اكتب في خانة الهاشتاجات مثل `#الصبر #الصلاة`، ثم احفظ. استخدم `_` لربط كلمات الهاشتاج الواحد.
- يمكن ربط الملاحظة بأكثر من هاشتاج، وإزالة التصنيف بتعديل الخانة.
- افتح «الهاشتاجات» من الفهرس أو صفحة المحور، أو اضغط هاشتاجًا أسفل ملاحظة.
- تعرض الصفحة الآية ثم الملاحظة. ملاحظات التدبر تعرض آيات الفقرة، والمقدمة تُعرّف كملاحظة عامة.
- الترتيب حسب رقم السورة ثم رقم الآية، مع الحفاظ على ترتيب الملاحظات داخل المجموعة.
- `tags` مصفوفة ضمن كائن الملاحظة نفسه؛ تستخدم الحفظ المحلي والمزامنة الحاليين. البيانات القديمة تظل صالحة.
- صفحة التجميع تقرأ مستندات `pages` من حساب المستخدم ثم تقارن timestamps مع النسخ المحلية. لا تحفظ نسخة فهرس منفصلة، ولا تنسخ نص الآيات؛ مصدر النص `QURAN_DATA`.

التحقق: `scripts/test-note-hashtags.cjs` يغطي الإضافة والتعديل وإزالة التصنيف وإعادة الفتح وترتيب السور والآيات وبيانات السحابة وتدبر الفقرة وتنقية HTML. يتطلب jsdom 26.
