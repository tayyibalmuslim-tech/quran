[مشروع «مصحف التدبر» (المستودع الحالي). الهدف: استكمال السور المتبقية (92 سورة، نحو 5,120 آية) على معيار سورة البقرة. العمل موزع على نموذجين ولكل منهما حدود لا يتجاوزها. احفظ هذه الكتلة حرفيًا في project-docs/pipeline/RULES.md وتعامل معها كمرجع ملزم لكل المهام.

الأدوار
1. النموذج الأعلى (المحتوى): ينتج التقسيم والعناوين ومعاني المفردات ومقدمة السورة كملفات JSON وتقارير مراجعة فقط. لا يكتب HTML أو CSS أو JS، ولا ينسخ نص الآيات.
2. النموذج البرمجي: يبني المولّد والفاحص ويدمج ويختبر. لا يكتب ولا يعدّل عنوانًا أو معنى أو حدّ مقطع. أي خلل علمي يُسجَّل ويُعاد إلى قائمة مراجعة المحتوى.

الثوابت
3. نص الآيات مصدره الوحيد assets/quran-data.js ويُحقن آليًا. لا يُكتب باليد ولا يُمس رسمه أو ضبطه.
4. التقسيم وحدة معنى يحفظها القارئ ثم ينتقل إلى التي بعدها، بلا حد ثابت لعدد الآيات أو الكلمات. المرجع الحاكم: project-docs/paragraph-order.md وقسم «معيار التقسيم» في project-docs/template.html. لا تُجزأ آية، ولا يُفصل جواب عن سؤاله ولا استثناء عن أصله.
5. «المعنى التفصيلي» حقل فارغ يكتبه المستخدم بنفسه. يُمنع توليد شرح جاهز لكل آية تحت أي اسم. الميزة البرمجية وملاحظات المستخدم تبقى كما هي.
6. معاني المفردات بمعيار البقرة: كل لفظ غريب في المقطع، والكلمة بالرسم العثماني حرفًا بحرف كما في الآية، والمعنى جملة واحدة تنتهي بنقطة بلا HTML وبلا علامة الاقتباس المزدوجة (تُستبدل بـ « »)، وعلامات الوقف خارج الكلمة. تُفتح المصادر فعليًا قبل الصياغة، ولا تُنسب عبارة إلى مصدر لم يُطَّلع عليه، ولا تُختلق إحالة، ولا يُوحى بإجماع غير متحقق. ما تعذّر توثيقه يُعلَّم unverified ولا يُعدّ جاهزًا.
7. السور الـ22 الموجودة لا تُعدَّل صفحاتها ولا حدود محاورها إلا بقرار مكتوب مني. السبب: الهايلايت يُخزَّن في المتصفح بمفتاح quran-tadabbur-hl-{السورة}-{المحور} كـ innerHTML، فأي تغيير في tooltips أو الحدود يُبطله.
8. كل صفحة مولّدة تحمل تنبيه الذكاء الاصطناعي نفسه الموجود أعلى الصفحات الحالية.
9. الحالات: لم يبدأ ← مسودة ← ينتظر المراجعة ← جاهز للتنفيذ ← مدمج ← متحقق منه، أو متعطل. لا تُكتب «جاهز» إلا بعد مراجعة فعلية للنص والمصادر، لا اعتمادًا على تقرير مهمة سابقة.
10. لا حذف ولا استبدال لمحتوى معتمد بلا سبب موثق. لا force push. لا دمج في main: كل دفع إلى main ينشر الموقع تلقائيًا على GitHub Pages.
11. عند نقص مصدر أو صلاحية: اذكر المطلوب بدقة وتوقف. لا تخمّن ولا تملأ بحشو.
12. كل مهمة تحدّث سجلها (progress-content.json للمحتوى، progress-code.json للكود) وتحدد المهمة التالية ثم تتوقف.]
